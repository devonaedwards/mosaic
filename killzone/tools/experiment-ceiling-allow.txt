# KILL ZONE - the experiment-drift checker's ceiling allowlist.
#
#   <experiment>  <the column, exactly as it prints>  # <tag>: <why>
#
# The ceiling detector (see check_experiment_drift.py) reports a percentage
# column that is pinned to a bound or does not vary at all, because FINDINGS 32
# is right that a measurement pinned to a ceiling is a constant rather than a
# result. Some constants are the point. This is where one says so, and an entry
# without a reason is a warning being suppressed, so the checker rejects it -
# the same rule, and the same shape of file, as tools/dead-symbols-allow.txt.
#
# The reason has to open with one of these tags:
#
#   structural  the ceiling is a property of the units in the comparison rather
#               than of the rungs the experiment chose, so no ladder can move
#               it. Measured, not assumed: an entry with this tag names the
#               sweep that was tried.
#   control     a deliberately degenerate arm, kept as the reference the live
#               arm beside it is read against.
#
# The column is matched by value, which is the whole point of writing it out:
# the day the numbers move, the entry stops matching and the warning comes
# back. An allowlist that keeps applying after the thing it excused has changed
# is the failure this project keeps naming.

vertical  100,100,100,100  # structural: the Gun Mount cannot engage the High band at all (Defs.cs, CanReachHigh false), so one high drone in the flight is outside the defence rather than evading it. Measured before being excused - flights of two, three and four quads across every split give 99-100% in every cell, so it is not the flight size. The column is the contrast the Autocannon arm beside it is read against, and the experiment's own commentary says so.

radar  0,0,0,0,0,0,0  # control: the parked column. A stationary vehicle has no radial component, so SimConstants.RadarNotchMetresPerSecond gates it at every range and on every heading - the deliberately degenerate arm the two moving columns beside it are read against, and the one cell-for-cell comparison in the table (same tank, same mast, same position, engine off). Measured before being excused: the two moving columns at the same seven offsets run 46-53% and 26-79%, so it is the motion and not the rungs.
fiber  100,100,0,0,0,0  # structural: three columns of the same shape - both 'site held' columns of the road arm and the radio control of the open arm. All three are one gate: a launch site is held when the defence's own passive listening reaches it and not when it does not, which on these rungs falls between 6,600 m and 9,600 m out. No rung choice moves a sensor reach, and the fiber column beside it on the open arm is the live one this is the comparison for - it reads 100% where this reads 0%, and that difference is the whole result of the experiment.
